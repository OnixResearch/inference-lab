## Scope and limitations

All executable harnesses in Batch 3 run deterministically on CPU as `bounded_contract_harness` checks, except `#14` (`rwkv-leaf`) which explicitly reports `execution_class = blocked_on_artifacts` until a second concrete non-mock native-RWKV consumer demonstrates the API. No physical CUDA GPU, DGX Spark GB10, Strix Halo, Tenstorrent P150x2, RTX 5080, compiled `ggml` CUDA binary, live `djev` HTTP server, JAX/Torch runtime, or Qwen3.8-27B weight serve is executed locally. All external upstream claims (AMARA, CRAM, Unsloth/MACaQ/Monoglot/ttf/QDA/vegaml, upstream DeepSeek training runs) remain strictly unverified and non-gating.
