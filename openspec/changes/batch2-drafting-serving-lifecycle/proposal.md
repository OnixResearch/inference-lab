# Batch 2: Drafting, serving, kernel-opt, KV-routing, recovery, and lifecycle contracts

## Why

Batch 1 bootstrapped `OnixResearch/inference-lab` with a deterministic, dependency-free pure-Rust core (`unsafe_code = "forbid"`), offline Nix tooling, and bounded contract harnesses for `#1`, `#40`, `#41`, `#43`, `#52`, `#56`, `#58`, and `#60`. Batch 2 extends the pure-Rust contract and reference-math foundation across the next ten tracked issues (`#2`–`#11`), covering masked proof completion, diffusion and adaptive speculative drafting, independent kernel-optimization gating, session KV routing and migration compatibility, portable serving benchmark extraction, DeepSeek/Spark serving migration, learned-compiler asset recovery, conditional structured-read gating, and single-host model lifecycle measurements.

## Scope and limitations

All executable harnesses in Batch 2 run deterministically on CPU as `bounded_contract_harness` checks, except `#9` and `#10` which explicitly declare `blocked_on_artifacts` alongside their device-free contract controls. No physical GPU (B200/H100/GB10/RTX 5080), Tenstorrent P150, Darwin/AppleContainer host, RDMA fabric, live Lean/Verus prover, or resident model service is executed locally. All external author claims (DFlash2 6.6x, DNeo 1.3x/701 tok/s, megakernel-zoo 1.13–2.05x, Diffusion-Proof pass@32+32, daVinci-Prover, Snarkify, Eunomia) remain strictly unverified and non-gating.
