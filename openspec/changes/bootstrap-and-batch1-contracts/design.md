# Design: Bootstrap and Batch 1 contracts

## Core architecture

- **Zero external dependencies**: all JSON emission (`src/json.rs`), SHA-256 digest computation (`src/json.rs`), reference dense transformer math (`src/stage.rs`), BPE tokenizer & chat-template rendering (`src/tokenizer.rs`), and contract evaluators use only Rust `std` with `unsafe_code = "forbid"`.
- **Shared provenance (`src/provenance.rs`)**: every harness emits `execution_class` (`bounded_contract_harness`, `unavailable_hardware_runtime`, `blocked_on_artifacts`), algorithm-tagged digests (`DigestRef`), non-collapsing `OutcomeStatus` values, and explicit hardware-availability gates.
- **Explicit imperative shell (`src/main.rs`)**: parses one subcommand (`benchmark`, `diffusion`, `trace`, `stage`, `power`, `tokenizer`, `related-work`) and `--out NEW_DIRECTORY`, creates a brand-new output directory, writes `inputs.json`, `results.json`, `summary.md`, and writes empty `COMPLETE` last.

## Per-issue contract design

1. **Bootstrap seed (`src/seed.rs`)**: frozen `serving-contract-v1` workload comparing three serving-admission profiles with explicit KV-cache OOM, timeout, invalid-template, and unsupported-backend outcomes.
2. **Issue `#1` (`src/diffusion.rs`)**: separates proposal, scorer, score transformation, objective, selection (`ArgmaxBestOfN` vs `WeightedResampling` vs `BoundedRepair`), and Noble hard admission (`Accepted`, `Invalid`, `Unsupported`, `Exhausted`, `InternalFailure`). Enforces immutable incumbent protection against frozen-region edits, stale base/diagnostic digests, malformed output, excessive candidates, and post-deadline arrivals. Includes offline pool replay and the default-off 3-format (`DependentWeave`, JSONL, socketteer nested JSON) tree interchange comparison with explicit field-loss lists.
3. **Issue `#40` (`src/trace.rs`)**: enforces run/module identity binding, clock-domain mapping with uncertainty bounds (forbidding raw cross-domain subtraction), scoped `(context_id, stream_id, correlation_id)` joins, batched-kernel `unavailable` attribution, event-loss completeness checks, and bounded deferred metadata resolution.
4. **Issue `#41` (`src/stage.rs`)**: implements a frozen 4-layer dense causal transformer in `f64` (RMSNorm, RoPE causal self-attention with stage-local KV cache, SwiGLU MLP, single greedy argmax sampler). Runs unsplit (`0..4`), 2-stage (`0..2` + `2..4`, full & chunked prefill + forced-token decode), 3-stage (`0..1` + `1..3` + `3..4`), and reset/reuse across generations. Enforces strict envelope validation, poisoned-buffer/stale-KV state transitions on timeout/cancel, and explicit `UnavailableHardwareRuntime` rejection (no silent CPU fallback) when Apple GPU or Tenstorrent P150 execution is requested.
5. **Issue `#43` (`src/power.rs`)**: separates `DeviceInstructionTileSpacing` from `HostInvocationCadence`, separates 7 timing phases and short-run vs sustained metrics, reuses `#40`'s clock/completeness/event-loss semantics, gates energy output strictly on actual sensor observations, and executes paired AB/BA `known-equivalent`, `wrong-but-fast`, and `order-drift` protocol controls.
6. **Issue `#52` (`src/tokenizer.rs`)**: implements deterministic BPE merge-rank encoding/decoding with special-token protection and UTF-8 fidelity, pinned `chatml-v1` and `qwen-thinking-v1` template rendering with role-boundary injection defense, and a backend parity verifier that reports every mismatch as `disqualifying_parity_mismatch`.
7. **Issues `#56`, `#58`, `#60` (`src/related_work.rs`)**: encodes pinned SHAs, undeclared-license gates, empty-repo/HTML-only non-pin flags, disambiguation notices, and unverified non-gating author claims, validated by a pure gate checker.
