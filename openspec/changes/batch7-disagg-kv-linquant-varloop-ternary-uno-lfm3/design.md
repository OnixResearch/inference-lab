# Batch 7 Design

## Architectural invariants

Every Batch 7 module preserves the pure-core / imperative-shell boundary established in Batches 1–6:

1. **Zero external dependencies and `#![forbid(unsafe_code)]`**: All wire codecs, tensor-parallel/KV-sharding references, recurrent algebra rewrites, ternary/Q4_0 quantizers, speculative/2DSD/Uno verifiers, MoVA/softplus attention blocks, calibration calculators, and negative controls reside in pure deterministic Rust 1.85.1 with zero filesystem, network, clock, process, or accelerator I/O.
2. **Strict NaN & zero-divisor safety**: No float `.max(...)` or `.min(...)` calls anywhere in Batch 7 code. Every floating-point input, intermediate, and metric is checked with `!v.is_finite()` -> `Err(...)`, comparisons use explicit finite-checked branches, and every denominator is guarded against `0` (`Option<f64>` returning `None` when empty or zero accepted).
3. **Independent reference verification & genuine numerical engines**:
   - `#62` (`disagg_kv_transfer`): Versioned KV prefix-cache wire framing codec (header, tensor metadata, chunk sequence, SHA-256 checksum) paired with miniature causal attention comparing single-host prefill+decode vs disaggregated wire-transferred KV decode (`<= 1e-12` exact parity), plus cold/warm TTFT and 10GbE wire bytes/token accounting.
   - `#63` (`spark_rdma_tp`): Independent single-node FP64 attention+FFN reference vs 2-rank RDMA tensor-parallel split with checksummed all-reduce (`<= 1e-12`), plus real 4-bit quantized KV attention parity vs FP64 gating throughput reporting at `8K`/`128K`/`1M` against replicated and layer-split baselines.
   - `#64` (`spark_kv_checkpoint`): 2-node cross-shard KV cache + deterministic binary disk-checkpoint save/resume serializer (`header + model/weight/tokenizer digest + per-shard SHA-256`) verified for exact token/logit parity (`<= 1e-12`) against fresh full recomputation, plus KV headroom and save/load I/O vs recompute TTFT comparison.
   - `#65` (`spark_copydrafter`): Isolated default-off `CopyDrafter` (longest-suffix context match) paired with exact greedy token-identity verification AND exact stochastic rejection sampling (`min(1, p/q)` + normalized residual + bonus token) vs non-drafted decoding on repetitive vs novel prompts, plus single-stream vs 16-stream tok/s, acceptance rate, and 131K–1M TTFT reduction.
   - `#66` (`hypertune_kv_adapters`): Miniature causal attention comparing unadapted base, prepended soft-prefill paged KV blocks (heterogeneous per-request adapters & composition verified `<= 1e-12` vs full prepended forward), and per-request low-rank LoRA `W + (alpha/r) B A`, with KV-block overhead, per-matrix bandwidth accounting, and independent co-resident task accuracy checks.
   - `#67` (`qwen38_longbook_gdn`): Miniature 4-layer hybrid (3 GDN + 1 full-attention) vs all-4-layer GDN conversion verifying exact `O(1)` constant GDN state vs `O(L)` KV-cache scaling across `8K`–`262K` and running independent needle/associative-recall and frozen agent-task checkers under matched serving/quantization provenance.
   - `#68` (`linquant_recurrent`): Real pure-Rust **Gated DeltaNet (GDN)** and **Mamba-2 (SSD)** recurrent prefill engines comparing: (a) direct FP64 sequential recurrence vs FP64 **LinQuant algebraic rewrite** (chunk/power-rescaled decay + orthogonal Hadamard / diagonal-balanced state-update form) verified for exact FP64 invariance (`<= 1e-12`) BEFORE quantization, and (b) naive low-precision (BF16 / FP8-E4M3 / INT8) vs LinQuant-rewritten low-precision prefill measuring state L2/max error and output logit error against FP64, keeping Blackhole kernel work explicitly linked to `tt-onix#34`.
   - `#69` (`varloop_budget_protocol`): Miniature variable-loop transformer (`R = 1, 3, 4, 5`) implementing exact greedy 2DSD early-loop block drafting + final-loop verification checked for token-identical losslessness BEFORE timing, first-loop vs final-loop argmax agreement, per-loop acceptance length, equal-serving-cost loop-count vs thinking-token comparison (using measured 2DSD cost, reporting repetition-filtered and unfiltered columns side-by-side on long-context reasoning vs closed-book knowledge), shared vs separate per-loop KV cache ablation (preserving `#89` boundary), quantization-vs-looping tradeoff, and strict Linux x86_64 + CUDA 13.0 + BF16 GPU host gate.
   - `#70` (`ttf_ternary_qwen`): Real pure-Rust ternary `{-1, 0, +1}` quantizer (absmean threshold, exact 5-trits-per-byte ~1.6 bpw pack/unpack round-trip, dequantized ternary matvec parity `<= 1e-12` vs scalar FP64 reference) vs real block-quantized `Q4_0` and FP64 baselines, measuring weight-bit density, MSE/SNR, logit KL divergence, VRAM footprint, and independently checked math/code/agent pass rates + `cost_per_accepted_task` (`accepted == 0 -> None`).
   - `#71` (`drafter_opd_replay`): Bounded open-loop replay harness with explicit noise-floor gating (interleaved repeat variance & MDE gate refusing within-noise claims) and lossless-vs-lossy verdict separation, running a real miniature drafter adaptation comparing frozen baseline, `Draft-OPD` on-policy KL distillation, and `D-PACE` rejection-point weighted updates with verified zero target-distribution drift on lossless arms.
   - `#72` (`k2_uno_mova`): Real pure-Rust **MoVA + overflow-safe softplus attention gating** vs standard softmax attention (verifying numerical stability, non-negativity, distinct entropy/sparsity, and finite outputs) plus a draftless **`Uno` adapter** multi-token predictor with target-model verification checked for exact lossless token equivalence (`0` mismatches) against standard AR decoding, alongside memory overhead and `batch = 1, 4, 8` scaling vs AR and MTP/speculative controls.
   - `#73` (`lfm3_d1_decision`): Default-off adapters for `LFM3-1.7B` (miniature tri-hybrid conv + recurrent + attention block verified for exact cached-vs-full parity `<= 1e-12` and `8K`–`256K` retention/memory scaling) and `d1-2B` single-pass typed decision model with strict schema conformance, exact ECE and Brier score computation, confidence-independent ground-truth checking, single-pass vs AR latency comparison, and explicit exclusion of `LFM3-Audio-2B` (`audio-lab#2`).
4. **Honest hardware/artifact separation & non-gating upstream pins**:
   - All 12 modules emit `default_enabled: false`, `synthetic_contract_fixture: true`, `execution_class: "bounded_contract_harness"`, and explicit `hardware_gate` (`unavailable_hardware_runtime` for `#62`, `#64`, `#65`, `#66`, `#67`, `#69`, `#70`, `#71`; `blocked_on_artifacts` for `#63`, `#68`, `#72`, `#73`).
   - All upstream repos/checkpoints checked on 2026-11-24 carry their exact observed 40-hex commit SHAs and SPDX licenses; unlocated/unverified upstream artifacts carry explicit honest offline pin statuses without fabricated SHAs.
   - Zero external X/blog/model-card/paper numbers are imported as pass/fail acceptance gates.
5. **Deterministic publication**: `src/batch7.rs` aggregates all 12 suites into a fresh directory with per-issue `inputs.json`, `results.json`, `summary.md`, 0-byte `COMPLETE` markers, top-level aggregate files, and SHA-256 `manifest.json`, with zero `/home/` path leaks and two-run byte-identical determinism.
