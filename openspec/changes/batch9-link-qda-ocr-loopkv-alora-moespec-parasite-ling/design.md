# Batch 9 Design

## Architectural invariants

Every Batch 9 module preserves the pure-core / imperative-shell boundary established in Batches 1–8:

1. **Zero external dependencies and `#![forbid(unsafe_code)]`**: All sparse-read attention comparators, mixed-precision quantizers, hierarchical extraction evaluators, Levenshtein OCR checkers, cross-loop INT2/LoopVQ KV compressors, delayed-suffix aLoRA/Hypertune prefix-KV verifiers, multi-node RDMA ordering simulators, sparse-MoE routing-overlap roofline governors, off-policy Anchor-Label Relabelling simulators, orthogonal subspace interchange/necessity/planted-parasite controllers, Ling-3.2-air 2x2 KV-dtype x allocator-cap harnesses, and negative controls reside in pure deterministic Rust 1.85.1 with zero filesystem, network, clock, process, or accelerator I/O.
2. **Strict NaN & zero-divisor safety**: No float `.max(...)` or `.min(...)` calls anywhere in Batch 9 code. Every floating-point input, intermediate, and metric is checked with `!v.is_finite()` -> `Err(...)`, comparisons use explicit finite-checked branches, and every denominator is guarded against `0` (`Option<f64>` returning `None` when empty, zero accepted, or unmeasured).
3. **Independent reference verification & genuine numerical engines**:
   - `#85` (`link_sparse_attention`): Miniature learned block-router sparse read vs exact dense causal attention (`L = 64, D = 8`), verifying `k = num_blocks` full-read exact parity (`<= 1e-12`) against dense attention, quantifying sparse top-k retrieval hit rate, output error, and attention-read reduction, and bounding default-off `128K`–`4M` retrieval + multi-hop end-task checks (`blocked_on_artifacts`).
   - `#86` (`mit_qda_quant`): Pure-Rust 6-layer linear/attention surrogate quantizer comparing FP64, uniform GGUF-INT4, uniform NVFP4, and sensitivity-guided QDA mixed-precision recipes under a matched average bit budget, computing exact layer MSE, effective bpw, logit KL divergence, Spearman rank correlation (`#18`), and independently checked task accuracy + `cost_per_accepted_task` (`None` at zero accepted).
   - `#87` (`knowledgator_sys1_extract`): Deterministic frozen 6-document hierarchical-extraction evaluator extending `#55`'s fixture structure to compare default-off `knowledgator_sys1_small`, pinned `clairic_flash_9b`, and `structured_output_llm_baseline` on exact-field precision/recall/F1, strict schema conformance, source-span grounding, and throughput while keeping model confidence strictly informational.
   - `#88` (`unlimited_ocr_longdoc`): Real pure-Rust Wagner-Fischer normalized Levenshtein edit-distance evaluator, cross-page table row-continuation checker, and heading-tree continuity verifier comparing default-off `unlimited_ocr_3b_single_pass` (32K context guard) against `page_chunked_ocr_baseline` across `12`, `40`, `64`, and `100`-page frozen PDF structure fixtures alongside memory and pages/sec accounting.
   - `#89` (`loop_kv_compression`): Real pure-Rust looped-transformer KV engine (`2` stored layers x `4` loops x `16` tokens x `8` dims) computing exact cross-loop cosine similarities, **ResidualQuant INT2** (2-bit symmetric residual quantizer with bit-exact 4-values/byte packing & cumulative reconstruction), **LoopVQ sub-1-bit** (`0.5` bpw and `0.25` bpw joint cross-loop codebook vector quantizer with bit-exact index packing), zero-residual exact identity parity (`<= 1e-12`), attention output error, and `O(L*K*N)` vs compressed KV byte accounting beside `#28` and `#69`.
   - `#90` (`alora_prefix_cache`): Real pure-Rust causal attention engine (`D = 8`, rank `2`, prefix `P = 8`, suffix `S = 4`) comparing `unadapted_base`, `standard_lora_full_sequence`, `alora_delayed_suffix` (`arXiv:2512.17910`), and `hypertune_soft_kv_adapter` (`#66`), proving **exact prefix-KV invariance (`<= 1e-12`)** and cached-prefix-vs-full equivalence (`<= 1e-12`) for `aLoRA` and `Hypertune` while quantifying standard LoRA's prefix-KV divergence, plus `1..128`-adapter shared-prefix TTFT, HBM usage, and independent task accuracy.
   - `#91` (`perseus_mpk_rdma`): Deterministic 2-node RDMA decode timeline & collective-ordering verifier comparing `naive_proxy_put_signal`, `perseus_decoupled_signaling`, and `mpk_sm_persistent_graph` beside `#61`, `#63`, and `#76`, verifying exact collective numerical/order parity (`<= 1e-12`) before reporting NIC fence stall fraction and 2-node DGX Spark latency envelopes.
   - `#92` (`moe_spec_roofline`): Real pure-Rust sparse-MoE (`16` experts, `top_k = 2`) router over `gamma = 1, 2, 4, 8` draft tokens measuring exact unique expert union `|U(gamma)|`, temporal expert-routing overlap ratio, batched-vs-sequential MoE verification parity (`<= 1e-12`), and an analytical memory-bandwidth + compute + KV-cache roofline governor (`arXiv:2610.38981`, `QuantSpec`, `MoE-SpeQ`) optimizing draft length vs naive dense roofline predictions.
   - `#93` (`anchor_label_drafter`): Real pure-Rust off-policy speculative rollout supervision-recovery engine comparing `naive_off_policy_truncated`, `anchor_label_relabelling` (`arXiv:2609.38795`), `draft_opd_on_policy`, and `d_pace_rejection_weighted` (`#71`) under exact matched gradient-step budgets, proving exact analytical rejection-sampling target-distribution losslessness (`<= 1e-12`), measuring cascade-recovery fraction, mean accepted length, replay throughput, and 2-sigma noise-floor gating.
   - `#94` (`parasite_feature_control`): Extends `#45` (`intervention-replay`) with typed `SubspaceInterchange` and `ProjectionAblation` manifest kinds whose SHA-256 digests cover basis, rank, layer, and token positions; strict orthonormality (`||B^T B - I||_inf <= 1e-9`) and rank validation; necessity ablation compared against 16 (`>= 10`) seeded matched-rank random orthonormal subspaces via Gram-Schmidt; explicit separate `sufficiency_passed`, `necessity_passed`, and `MechanismClassification` (`found_mechanism` / `sufficient_not_necessary` / `insufficient`); a planted-parasite backend variant where rank-2 interchange on `span(e_0, e_1)` passes sufficiency while ablation yields `sufficient_not_necessary`; a positive control passing both sufficiency and necessity; and bit-identical replay receipt verification.
   - `#95` (`ling_fp8kv_alloc_cap`): Default-off pinned single-Spark `Ling-3.2-air` NVFP4 profile (`tonyd2wild/Ling-3.2-air-NVFP4-DGX-Spark@d2548801`, `MIT`) reusing `#35` (`NemotronServingProfile`) and `#11` (`MemoryCounterObservation`), freezing a 2x2 KV-dtype (`bf16`/`fp8`) x allocator-policy (`stock`/`capped` via `FP8FIX_TORCH_GROWTH_GIB`) matrix plus MTP off/on stage whose digests incorporate KV dtype, allocator cap, MTP draft count, `--gpu-memory-utilization`, max context (`262144`), and patch file digests; rejecting floating tags and missing-patch arms as `Unsupported`; enforcing a hard `MemAvailable` brake without silent retry; evaluating multi-depth needle recall (`32K`/`128K`/`215K+` across depths `0.0..0.95` with depth `0.0` flagged as memory-pressure check only) and full-pool stress; running real pure-Rust miniature MLA BF16-KV vs FP8-E4M3-KV and isolated 1-stage decode kernel parity; and reporting `1K`/`32K` MTP throughput with local noise floor.

   - All 11 modules emit `default_enabled: false`, `synthetic_contract_fixture: true`, `execution_class: "bounded_contract_harness"`, and explicit `hardware_gate` (`blocked_on_artifacts` for `#85`–`#88`; `unavailable_hardware_runtime` for `#89`–`#95`).
