# Batch 4: MTP decoder, FlashTopK, MACaQ-R, heterogeneous rollouts, NVFP4/MXFP8, Spark engines, KV compression, expert placement, vision in-fusion, and Qwen3.8 QSA contracts

## Why

Batches 1–3 established `OnixResearch/inference-lab` with a deterministic, dependency-free pure-Rust core (`unsafe_code = "forbid"`), offline Nix tooling, and bounded contract harnesses for `#1`–`#21`, `#40`, `#41`, `#43`, `#52`, `#56`, `#58`, and `#60`. Batch 4 extends this pure-Rust numerical reference, contract verification, and provenance foundation across the next ten tracked issues (`#22`–`#31`), covering:

- `#22`: small CPU MTP draft-and-verify decoder with separate target/MTP caches, sentinel-poisoned rollback, greedy exact parity, and exact/empirical stochastic rejection sampling;
- `#23`: FlashTopK fused sparse-indexer reference, SM90/SM100 vs SM120/SM121 & 32-head vs 64-head capability gates, canonical tie/padding ordering, and underflow/overflow recovery;
- `#24`: MACaQ-R native MoE K-quant (`Q4_K`/`Q5_K`/`Q6_K`) refinement reference preserving block scales/basis and unchanged out-of-scope tensors, creation vs serving accounting, and held-out task checks;
- `#25`: heterogeneous rollout serving and versioned `http-lora` tensor activation with probe-verified identity, fleet-reconciliation failure modes, and bounded two-backend mixed-pool accounting;
- `#26`: NVFP4 forward / stochastic MXFP8 backward linear-layer numerical reference, surrogate gradient & operand-covariance statistics, NVIDIA Transformer Engine `_compute_mxfp8_support()` SM120/SM121 refusal matrix, Model Optimizer reconstruction, and optional Fabric `#6` Hadamard/S2F6 codec reference;
- `#27`: Hyperflare and TensorRT Edge-LLM DGX Spark qualification matrix, KV+recurrent continuation parity (append/branch/rollback/pause/cancel), and `#11` lifecycle accounting;
- `#28`: KVPress long-context KV compression reference (uncompressed, identity, and two lossy arms), observed KV + temporary buffer accounting, frozen RULER-style diagnostics, and independently checked evidence-grounded end tasks;
- `#29`: RustingStrata vs `llama.cpp` response-derived MoE expert placement and host-page residency (`STRATA_FIXED_EXPERTS`, `STRATA_COLD_KEEP`), 5-layer warm-state isolation, routing-equivalence observability, and custom license review;
- `#30`: matched-visual-capacity comparison of separate vision encoders, early vision-only FFN in-fusion, and early full in-fusion (plus encoder-free reference), single-vs-packed mixed-batch parity, strict modality/attention mask separation, and explicit `quality_unestablished` reporting;
- `#31`: Qwen3.8-27B QSA 4-token block-level sparse attention vs matched dense control (`LLAMA_QSA_DENSE=1`) `2x2` matrix with MTP, retained full target KV + indexer memory accounting, and independently checked start/middle/end long-context tasks.

## Scope and limitations

All executable harnesses in Batch 4 run deterministically on CPU as `bounded_contract_harness` checks. Physical NVIDIA SM90/SM100/SM120/SM121/GB10/RTX 5080 GPUs, heterogeneous NVIDIA/AMD serving pools, full 22.36 GB / 27B / 35B / 398B GGUF or HF weight serves, compiled Transformer Engine / CUTLASS / Hyperflare / TensorRT Edge-LLM / RustingStrata / QSA `llama.cpp` binaries, and trained multimodal checkpoints are explicitly recorded as `unavailable_hardware_runtime` (or `blocked_on_artifacts` where trained model variants are absent). All external upstream claims (FlashTopK 5,317→1,623 ms, MACaQ-R KL 0.015731→0.013367, ai& heterogeneous RL, Thinking Machines / Four Over Six / Quartet II / TetraJet-v2, Hyperflare 3-Spark recipe, RustingStrata 64.6 vs 48.6 tok/s, Unbundling 210/171/182 ms, QSA 1.793×/2.921×) remain strictly unverified non-gating references.
