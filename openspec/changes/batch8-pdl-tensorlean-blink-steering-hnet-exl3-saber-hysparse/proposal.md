# Batch 8: PDL & breakable CUDA graphs, TensorLean verification boundary, Blink CPU-free serving, Qwen3.5-4B two-neuron steering, H-Net v2 byte modeling, TKCC hill-climb profiling, EXL3 2.25-bpw long-context quant, saber-engine + DFlash2 power-capped serving, MiMo HySparse2 KV projection, apple-nvidia-sidecar split inference, and ML-and-silicon co-design audit

## Why

Batches 1–7 established `OnixResearch/inference-lab` with a deterministic, dependency-free pure-Rust core (`unsafe_code = "forbid"`), offline Nix tooling (Rust 1.85.1), and bounded contract harnesses covering issues `#1`–`#73`. Batch 8 implements the next eleven tracked issues (`#74`–`#84`), all strictly default-off:

- `#74` (`pdl-breakable-graphs`): Related-work record for Baseten's DeepSeek-V4.1-Flash optimization write-up (`@thealexker`, X post `2117989442090598798`), isolating Programmatic Dependent Launch (PDL) overlap and breakable prefill CUDA graphs behind default-off toggles on a pinned flash-MoE fixture, verifying exact numerical parity (`<= 1e-12`) against standard launches, and measuring kernel-gap bubbles and TTFT using correlated host/GPU trace spans (`#39`, `#40`).
- `#75` (`tensorlean-kernel-verify`): Related-work record for TensorLean (CertiK + Columbia, `@RonghuiGu` X post `2123786837797773807`, `blocked_on_artifacts`), documenting its formal verification scope and TCB assumptions, bounding a default-off Lean formal-verification check boundary on a pinned small reference tiled-GEMM / causal-softmax kernel, and comparing symbolic/formal invariant coverage against differential numerical testing across seeded kernel bugs (`#15`, `#52`).
- `#76` (`blink-cpu-free-serving`): Related-work record for Blink (`@thesupermannx` X post `2123339605311111649`, `blocked_on_artifacts`), logging SmartNIC GPUDirect RDMA and persistent GPU scheduling assumptions, modeling host-scheduled serving (vLLM/SGLang-style CPU control plane) vs GPU-resident persistent scheduling under controlled host-CPU interference (`idle`, `moderate`, `heavy`) for P50/P99 TTFT and decode jitter, and bounding a default-off RDMA-to-GPU qualification gate (`#39`, `#40`, `#61`).
- `#77` (`qwen35-neuron-steering`): Default-off reproducible intervention regression fixture extending `#45` (`intervention-replay`) with the exact Qwen3.5-4B two-neuron `down_proj` steering recipe (`L14 N8949 +1`, `L13 N7956 -1`, scaled by `dose * median(||resid||) / ||W_down[:, n]||` at `down_proj`, `@_lyraaaa_` X post `2113833330429083662`), verifying deterministic bit-identical replay and dose-response curves against unsteered and matched-L2-norm random-direction controls.
- `#78` (`hnet-byte-modeling`): Related-work record for H-Net v2 byte-level hierarchical modeling (`@_albertgu` X post `2115502110578290900`, `blocked_on_artifacts` pending public weights/code), paired with a pure-Rust byte-level UTF-8 boundary dynamic chunking and hierarchical encoder/upsampler reconstruction parity fixture (`<= 1e-12`) compared against BPE tokenizer edge cases (`#52`) and decode-step overhead accounting.
- `#79` (`tkcc-hillclimb-profile`): Related-work record for Together Compiler (TKCC, `@simran_s_arora` X post `2118032475498983540`) beside `#53` and `#61`, paired with a local hill-climb experiment-cycle bottleneck profiler decomposing `compile`, `warm_up`, `parity_check`, `measurement`, and `teardown_overhead` phases with Amdahl ceiling analysis and failure-retaining candidate throughput denominators.
- `#80` (`exl3-longctx-quant`): Default-off qualification pinning `pepuscz/strix-halo-llm@529935497a97bc61a1d71aea9a8864f81ebc82bb` (`MIT`) and `mw00/project-maya#908` (`@jgattermayer` X post `2119088009895448590`) for EXL3 2.25-bpw quantization on DeepSeek-V4.1-Flash at `128K`–`1M` context vs 4-bit/FP4 and FP64 baselines, including a pure-Rust exact `2.25`-bpw (36 bits per 16-weight tile) trellis/block quantizer with bit-exact pack/unpack and matvec parity (`<= 1e-12`), plus independently checked long-context reasoning and coding tasks (never needle-in-a-haystack alone).
- `#81` (`saber-dflash2-power`): Default-off qualification pinning `GGZ14/saber-engine@1da27661b3bf8a702a7532c8d17651de8c635e44` (`Apache-2.0`, `@QwenAIFans` X post `2119100011048767551`) with DFlash2 speculative decoding on Qwen3.8-27B, gating acceptance-length, TTFT, and sensor-gated power-capped `tok/s/W` (`#3`, `#43`) strictly behind greedy and stochastic numerical/token parity against vLLM/llama.cpp references.

- `#83` (`apple-nvidia-sidecar`): Related-work record pinning `joesinvestments/apple-nvidia-sidecar@c59a276a1ce5fc3c2e12e05f070a0180550cb619` (`MIT`, `@JoesInvestments` X post `2119450204512419959`) beside `#41` and `#42`, verifying a pure-Rust heterogeneous Apple-host + discrete-NVIDIA-eGPU split transformer stage contract (`<= 1e-12` parity vs single-device baseline), link bandwidth, stage handoff latency, concurrency scaling, and zero silent CPU fallback.

## Scope and limitations

All executable harnesses in Batch 8 run deterministically on CPU as `bounded_contract_harness` checks (`synthetic_contract_fixture: true`, `default_enabled: false`). Physical Blackwell/DGX Spark SGLang flash-MoE runs, SmartNIC GPUDirect RDMA clusters, Qwen3.5-4B physical serving, Strix Halo APU + RX 7900 XTX 1M-context serves, dual-R9700 210W power-capped `saber-engine` serves, Mac Studio + eGPU RTX 5090 Strata/tinygrad split links, physical silicon tapeouts, and unlocated/unverified upstream artifacts (`TensorLean`, `Blink`, `H-Net v2`, `TKCC`, `MiMo HySparse2`, `arXiv:2611.18859` silicon artifacts) are explicitly recorded as `unavailable_hardware_runtime` or `blocked_on_artifacts`. All external X posts, articles, videos, and paper figures remain strictly unverified non-gating references.
