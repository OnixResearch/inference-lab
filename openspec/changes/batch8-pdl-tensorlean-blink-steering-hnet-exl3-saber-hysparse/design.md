# Batch 8 Design

## Architectural invariants

Every Batch 8 module preserves the pure-core / imperative-shell boundary established in Batches 1–7:

1. **Zero external dependencies and `#![forbid(unsafe_code)]`**: All fused flash-MoE parity fixtures, symbolic kernel-bug verifiers, host-vs-GPU scheduler simulators, two-neuron `down_proj` steering fixtures, byte-level dynamic chunkers, hill-climb cycle profilers, 2.25-bpw trellis/block quantizers, power-capped speculative parity checkers, causal encoder-decoder KV projectors, Apple+eGPU split stage contracts, pre-silicon roofline auditors, and negative controls reside in pure deterministic Rust 1.85.1 with zero filesystem, network, clock, process, or accelerator I/O.
2. **Strict NaN & zero-divisor safety**: No float `.max(...)` or `.min(...)` calls anywhere in Batch 8 code. Every floating-point input, intermediate, and metric is checked with `!v.is_finite()` -> `Err(...)`, comparisons use explicit finite-checked branches, and every denominator is guarded against `0` (`Option<f64>` returning `None` when empty, zero accepted, or unmeasured).
3. **Independent reference verification & genuine numerical engines**:
   - `#74` (`pdl_breakable_graphs`): Miniature fused QK-norm + top-2 MoE router + mHC residual block comparing standard sequential launches, default-off PDL weight-prefetch overlap, and default-off breakable prefill CUDA-graph replay, enforcing `<= 1e-12` numerical parity BEFORE reporting correlated host/GPU kernel-gap bubble reduction and TTFT deltas (`#39`, `#40`).
   - `#75` (`tensorlean_kernel_verify`): Pinned small reference tiled-GEMM and causal-softmax kernel paired with a symbolic algebraic/index-invariant checker (modeling the bounded Lean proof obligation boundary and explicit TCB assumptions) and differential numerical testing over 5 seeded kernel bugs (tile-boundary OOB, missing reduction carry, softmax shift/scale defect, FP16 accumulator overflow/truncation, causal-mask off-by-one), explicitly comparing formal-invariant coverage vs finite-input differential testing (`#15`, `#52`).
   - `#76` (`blink_cpu_free_serving`): Deterministic discrete-event serving simulator comparing host-CPU-scheduled serving (vLLM/SGLang-style control plane with CPU scheduling + launch bubbles) against GPU-resident persistent scheduling across `idle`, `moderate`, and `heavy` host-CPU contention levels, reporting P50/P99 TTFT, decode ITL jitter, and colocated/isolated resilience ratios (`#39`, `#40`, `#61`) plus a default-off SmartNIC GPUDirect RDMA qualification gate.
   - `#77` (`qwen35_neuron_steering`): Extends `#45` (`intervention_replay`) with a miniature pure-Rust multi-layer SwiGLU/MLP transformer implementing the exact `#77` two-neuron `down_proj` scaling equation `delta_j = sign_j * dose * median(||resid||) / ||W_down[:, n_j]||` for `L14 N8949 (+1)` and `L13 N7956 (-1)`, deterministic replay digest verification, dose-response sweeps (`0.0` to `2.0`), and matched-L2-norm random-direction controls.
   - `#78` (`hnet_byte_modeling`): Pure-Rust byte-level UTF-8 boundary dynamic chunker + hierarchical encoder/upsampler reconstruction parity check (`<= 1e-12` exact byte reconstruction) evaluated on tokenizer-hostile edge cases (UTF-8 multibyte, emoji ZWJ, indentation/whitespace, digit-boundary arithmetic, role-injection delimiters) beside a BPE baseline (`#52`), reporting compression ratio, decode step overhead, and edge-case failure counts while gating execution behind public H-Net v2 weights/code (`blocked_on_artifacts`).
   - `#79` (`tkcc_hillclimb_profile`): Experiment-cycle bottleneck profiler beside `#53` and `#61` decomposing local hill-climb iterations into `compile`, `warm_up`, `parity_check`, `measurement`, and `teardown_overhead` durations, computing per-phase Amdahl speedups, preserving failed/rejected/parity-disqualified candidates in throughput denominators, and rejecting shortcuts that omit parity verification.
   - `#80` (`exl3_longctx_quant`): Real pure-Rust **2.25-bpw trellis/block quantizer** (16-weight tiles packed into exactly 36 bits = 4.5 bytes = `2.25` bpw via orthogonal Walsh-Hadamard incoherence rotation + 2-bit trellis payload + 4-bit shared tile exponent/scale), verifying bit-exact pack/unpack round-trip and dequantized matvec parity (`<= 1e-12` vs scalar FP64 reference), comparing MSE/SNR/logit KL against 4-bit/FP4 and FP64 baselines, and evaluating independently checked long-context reasoning and coding tasks (explicitly separated from needle-in-a-haystack!) across `128K`–`1M` context with VRAM/throughput and `cost_per_accepted_task` (`None` at zero accepted).
   - `#81` (`saber_dflash2_power`): Pinned `GGZ14/saber-engine@1da27661` (`Apache-2.0`) default-off arm with DFlash2 speculative decoding on Qwen3.8-27B (`#3`, `#43`), verifying greedy token identity and exact stochastic rejection-sampling parity against vLLM/llama.cpp target references BEFORE admitting acceptance length, TTFT, and sensor-gated power-capped `tok/s/W` and `J/token` metrics (treating missing/uncalibrated power telemetry as `unknown`, never zero).
   - `#82` (`mimo_hysparse2_kv`): Real pure-Rust **causal encoder-decoder KV projection engine** modeling MiMo HySparse2's prompt-only encoder depth (e.g. `25/49` ratio scaled in miniature 2-encoder + 2-decoder layers) where decoder layers project K/V from causal encoder hidden states, verifying exact cached incremental decode vs full recomputation (`<= 1e-12`), strict causal mask non-leakage, prefill FLOP and KV-byte accounting from `8K` to `1M` context vs dense full-layer baseline, and independent long-context accuracy checks (`#28`).
   - `#83` (`apple_nvidia_sidecar`): Pinned `joesinvestments/apple-nvidia-sidecar@c59a276a` (`MIT`) heterogeneous Apple-host + discrete-NVIDIA-eGPU split transformer stage contract (`#41`, `#42`), verifying exact single-device vs 2-stage split numerical parity (`<= 1e-12`) across prefill, forced-token decode, and cache reset, accounting for Thunderbolt/USB4/PCIe link bandwidth, activation payload bytes, stage handoff latency, concurrency scaling (`1, 2, 4, 8`), and zero silent CPU fallback.
   - `#84` (`silicon_codesign_audit`): Structured pre-silicon assumption audit for `arXiv:2611.18859` comparing workload, precision, memory-bandwidth, and energy-per-token projections via deterministic roofline and energy-balance models against measured-style lab hardware baseline envelopes (`#43`), explicitly classifying every gap that requires fabricated physical silicon to validate.
4. **Honest hardware/artifact separation & non-gating upstream pins**:
   - All 11 modules emit `default_enabled: false`, `synthetic_contract_fixture: true`, `execution_class: "bounded_contract_harness"`, and explicit `hardware_gate` (`unavailable_hardware_runtime` for `#74`, `#77`, `#79`, `#80`, `#81`, `#83`; `blocked_on_artifacts` for `#75`, `#76`, `#78`, `#82`, `#84`).
   - All public GitHub repos checked on 2026-11-24 (`pepuscz/strix-halo-llm`, `GGZ14/saber-engine`, `joesinvestments/apple-nvidia-sidecar`) carry exact 40-hex commit SHAs and SPDX licenses; unlocated/unverified upstream artifacts carry explicit honest offline pin statuses without fabricated SHAs.
   - Zero external X/article/video/paper numbers are imported as pass/fail acceptance gates.
5. **Deterministic publication**: `src/batch8.rs` aggregates all 11 suites into a fresh directory with per-issue `inputs.json`, `results.json`, `summary.md`, 0-byte `COMPLETE` markers, top-level aggregate files, and SHA-256 `manifest.json`, with zero local home-directory path leaks and two-run byte-identical determinism.
